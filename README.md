# 🌐 Portfolio Website

A modern, responsive, and interactive portfolio website developed using HTML, Tailwind CSS, and JavaScript to highlight my technical expertise, featured projects, research publications, certifications, and professional profiles, reflecting my journey as a developer and researcher.



---

## 🚀 Live Demo

🔗 [Visit Portfolio](https://elma-123.github.io/Portfolio/)

---

## 🌟 Features

- 📱 Responsive design that works on all devices
- ✨ Smooth scrolling navigation
- 🎨 Interactive UI elements with hover effects
- 📧 EmailJS integration for contact form
- 🪟 Glass morphism design elements
- ⚡ Animated sections and transitions
- 📜 Custom scrollbar
- 📲 Mobile-friendly navigation menu

## ⚙️ Setup and Installation

### 1️⃣ Clone the repository

```bash
git clone https://github.com/elma-123/Portfolio.git
```

### 2️⃣ Replace EmailJS credentials in `script.js`

```javascript
emailjs.init("YOUR_PUBLIC_KEY");
```

### 3️⃣ Update the following in `index.html` :

- 🖼️ Profile image
- 👤 Personal information
- 🔗 Social links
- 💼 Project details
- 🏆 Certificates
- 💻 Publications <br>..................................................

---
## 📧 Contact Form Setup

1. 📩 Create an EmailJS account.
2. 📝 Set up an email template.
3. 🔑 Update the following in `script.js`:

- Service ID
- Template ID
- Public Key
